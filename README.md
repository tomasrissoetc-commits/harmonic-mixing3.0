# Harmonic Mixing · Camelot Wheel

App interactiva para practicar mezcla armónica con Camelot Wheel.

## Incluye
- Rueda Camelot interactiva
- Explorador de mezclas compatibles
- Sección de teoría
- Quiz de práctica
- Tabla completa
- Reglas corregidas: Energy Boost, Diagonal Mix, Jaws Mix y Mood Shifter

## Cómo usar
Abrí `index.html` en el navegador o subí todos los archivos a un repo y activá GitHub Pages.
